# 学生社区需求与验收

学生登录后浏览通过审核的问题、按分类筛选、关键词搜索与分页，发布问题和回答默认待审核。作者在个人中心查看本人各状态内容及驳回原因，非作者只可读取公开内容。收藏只针对通过问题，当前身份隔离并幂等。

管理员复用 Session 登录，独立管理页面审核待审核问题/回答，驳回必填原因，保留审核人及时间，重复审核返回冲突。分类可新增、修改、启停，停用后历史内容保留且新发布拒绝。

验收覆盖学生 A/B/管理员身份、未登录/CSRF/越权/未知字段拒绝、并发收藏与审核、分类停用与发布的一致性、搜索分页及安全文本显示。全部页面具备加载、空、失败、禁用状态，375 至 1920px 正常使用。

保留现有认证、Agent 与 RAG 功能，社区表独立。功能范围遵循本次用户任务，问题编辑删除、私信、嵌套评论、图片上传、通知及 AI 社区功能留待单独任务。
