# AI 智能问答界面规范

## 视觉与页面结构

复用现有 `variables.css` 的蓝白主题、Inter 与系统中文字体和 Element Plus 变量。页面背景使用 `--color-background`，正文使用 `--color-text`，边框使用 `--color-border`。主操作采用 `--color-primary`，用户气泡采用现有浅蓝主题变量。正文 15px，行高 1.75，辅助信息 12 至 13px，当前会话标题 18 至 20px。标题和长文本允许换行。

继续使用 StudentLayout 的品牌、身份刷新和退出。顶部提供“学生社区”和“AI 智能问答”导航，通过当前路由表现选中态。Agent 页面采用该布局的紧凑主内容样式，页面高度由 `100dvh` 扣除实际 Header 占用，消息区域独立滚动，输入框保持可见。所有网格和 flex 子项设置 `min-width: 0` 与必要的 `min-height: 0`。

桌面工作区包含左侧历史、中央消息及底部输入区域。左侧宽度 264px，中央区域占用剩余空间，消息和输入内容最大宽度 860px 并居中。主工作区最大宽度 1440px，1920px 视口保留舒适留白。工作区四周留白 20 至 32px，卡片圆角沿用主题，并以细边框建立分区。

## 响应式

| 视口 | 布局 |
| --- | --- |
| 1024 至 1920px | 持续显示 264px 历史栏，消息区横向填满剩余空间 |
| 768 至 1023px | 历史收起为左侧抽屉，顶部显示“历史会话”按钮，消息内容保持居中 |
| 375 至 767px | 单列聊天，左右留白 12 至 16px，标题允许截断并保留完整 title，抽屉宽度 `min(320px, 88vw)` |

375px 下顶部导航、账号和退出允许有序换行。输入区底部 padding 加入 `env(safe-area-inset-bottom)`，采用动态视口高度适应软键盘。Markdown 代码块和表格仅在自身内部横向滚动。页面整体无横向滚动。

## 历史会话

侧栏上方放置“新建对话”主按钮，下方展示分页历史。条目显示标题与简短更新时间，当前条目用浅蓝背景、蓝色文字和 `aria-current` 标识。每项通过可聚焦的独立按钮提供“重命名”和“删除”，手机端持续可见，不依赖悬停。

新建后立即选中新会话并将焦点移到输入框。切换历史时先显示加载状态，防止短暂显示上一会话内容。移动端选择后关闭抽屉并恢复焦点。分页使用“加载更多”，加载期间禁用，失败时保留已加载列表并提供重试。

重命名使用 ElDialog、ElInput 与确定/取消按钮，标题长度按 API 契约限制。删除使用明确写有会话名的确认框，说明删除会话和消息，成功后选择可用会话或显示空状态。生成期间切换、新建和删除应先停止并释放当前请求，再切换状态。

## 聊天消息

顶部展示当前标题及生成状态，空标题回退“新对话”。无历史时展示简洁的“有什么想了解的？”和输入说明，可提供两个点击后填入输入框的示例问题。示例问题不得被展示为已有知识库内容。

用户消息右对齐，以浅蓝气泡承载。助手消息左对齐，白色背景或轻量边框，最大可用宽度用于较长推理和代码。每条消息有可读的“你”或“AI 助手”角色标签。助手正文用净化后的 Markdown 渲染，代码块使用等宽字体和语法高亮，代码块顶部提供语言标识与“复制代码”按钮。消息下方提供“复制回答”，复制失败显示明确反馈。链接在新标签打开并设置 `noopener noreferrer`，仅允许安全协议。

流式输出保留已收到的文字，用简短“正在生成…”状态提示。仅当用户接近底部时跟随新内容滚动，用户向上查看历史后保留其位置，并显示“回到底部”按钮。屏幕阅读器通过独立 `role=status` 的状态区域感知开始和结束，避免对每个 token 重复朗读。

## 输入与生成

输入使用 ElInput textarea，自适应 2 至 6 行，提供持久可读标签“输入问题”。底部提示“Enter 发送 · Shift+Enter 换行”。中文输入法 composition 期间 Enter 不发送。空白输入、未选中会话、历史加载期间和正在发送期间禁用发送。达到长度限制时显示计数与校验反馈，保留用户输入。

生成期间展示“停止生成”按钮，输入可保留下一条草稿，发送保持禁用。停止后消息标为“已停止”，保留部分回答，并允许再次发送。失败消息显示“生成失败”及“重试”按钮，重试必须由用户主动触发。重试使用先前问题和当前会话，页面避免重复叠加乐观用户消息。

## RAG 引用

助手消息下方有可展开的“参考资料（数量）”。每条使用独立引用卡片显示真实文档名、内容片段及后端提供的页码或来源标识。内容使用文本绑定，允许换行。列表默认收起长片段，通过“展开”和“收起”按钮操作。无引用时省略该区域。

只使用契约中对学生开放的字段。服务端绝对路径、数据库信息和不可信链接不得进入可见标签或 HTML 属性。文档名缺失时使用“参考资料”，页码缺失时省略页码。

## 状态及反馈

| 状态 | 页面反馈与可用操作 |
| --- | --- |
| 会话加载中 | 对应区域 loading 或骨架，保留页面布局 |
| 无会话 | 空状态与“新建对话”按钮 |
| SSE 中断 | 保留已接收内容，标记失败，提供主动重试 |
| 用户停止 | 标记“已停止”，恢复发送与切换 |
| 429 | 显示服务端安全的限流提示，允许稍后重试 |
| 403 | 行内权限或安全校验反馈，保留当前输入与身份 |
| 401 | 沿用认证失效流程，清理聊天状态并回登录 |
| 创建、重命名、删除失败 | 保留原列表和选中状态，展示错误并可再次操作 |

错误优先显示在操作相关位置，使用 ElAlert 或消息状态说明，避免只显示短暂 Toast。服务端原始异常、请求配置和密钥不能进入错误文案。

## 可访问性与验收

主要操作点击区域至少 44px，所有图标按钮提供中文 `aria-label`，保留全局 `focus-visible`。历史使用具名导航区域，消息使用具名日志区域，输入使用 form 语义。抽屉和对话框使用 Element Plus 的焦点管理，关闭后焦点回到触发按钮。禁止仅用颜色区分正在生成、失败、取消和选中。

尊重现有 `prefers-reduced-motion` 规则。分别检查 375、390、768、1366 和 1920px，覆盖长会话标题、长代码、表格、长文档名、空状态、加载、失败、取消、抽屉和键盘操作。功能验收通过实际页面和浏览器检查记录进入 test-report.md。
