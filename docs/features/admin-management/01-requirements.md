# 管理员后台与全系统UI需求

本轮补齐全部问题/回答搜索筛选、逻辑删除恢复、学生账号启停、真实统计、只读管理审计。保留既有审核分类与身份认证，社区与AI数据独立。删除与审核状态独立，恢复保留原状态。删除关联内容从学生所有入口隐藏，原数据保留。

同轮升级管理员独立导航布局、六业务页面、统一Design Tokens，并优化社区、AI工作台和登录注册。设计必须包含真实信息层级、筛选操作区、阅读与聊天区域、移动Drawer、加载失败空态及可访问性，实际修改页面并浏览器验收。无趋势数据时仅真实指标卡与待办。

验收包括管理员/学生/匿名与CSRF、用户Session实时禁用、删除恢复关联数据与审计一致性、并发冲突、数据保留、六视口与模态层键盘交互，以及社区/认证/AI普通和SSE/RAG/历史隔离回归。接口与统计口径以03-api-contract为准。
