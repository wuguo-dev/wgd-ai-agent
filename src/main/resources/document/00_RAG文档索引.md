# RAG 文档索引

## 文档用途

本目录面向大学生学习问答与 Spring Boot 技术问答场景，采用“主题元数据 + 独立问答块”的结构。每个问答块都可以单独切分、建立向量索引或作为知识库检索单元。

## 文档清单

| 文档 | 主题 | 建议检索关键词 |
|---|---|---|
| `01_大学生高数学习方法_FAQ.md` | 高等数学学习策略、复习方法、错题管理、考试准备 | 高数学习、极限、积分、刷题、错题本、复习计划 |
| `02_高数基础知识_FAQ.md` | 极限、导数、积分、级数、多元函数、微分方程等基础概念 | 高数基础、导数、积分、极限、级数、微分方程 |
| `03_SpringBoot常见问题_FAQ.md` | Spring Boot 项目搭建、配置、依赖注入、Web、数据访问、测试与部署 | Spring Boot、自动配置、注入、Controller、事务、Actuator |

## 推荐切分规则

1. 以 `## FAQ-编号` 作为一个优先级较高的语义块边界。
2. 将“问题”“回答”“关键词”“相关问题”保留在同一块中，避免只切出答案而丢失问题语义。
3. 建议保留 `文档ID`、`FAQ编号`、`主题`、`难度` 等元数据。
4. 对于问答系统，可先使用“问题 + 关键词”做混合召回，再将“回答”作为上下文。

## 回答风格

- 面向本科生和 Java 初学者，先给结论，再解释原因。
- 公式使用 LaTeX 行内格式，例如 `$f'(x)$`、`$\\int_a^b f(x)\\,dx$`。
- 对容易混淆的概念增加“常见误区”，帮助检索到纠错信息。
